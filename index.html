Three ideas

Built for people who just want to write.

No accounts, no markup, no learning curve. The kind of tool that disappears the moment you start typing.

01 / matrix

Real dots, not a font

237 hand-built glyphs drawn dot by dot on a dim field — the way a Nothing-OS display lights up. café, über, Kraków all render as themselves.

02 / files

Your notes, your disk

Each note is a plain .rtf in a plain folder. Folders nest, notes and folders drag between them, and everything is yours — readable by any app, forever.

03 / quiet

Nothing in the way

No syntax, no markers, nothing to interpret. Smart quotes and substitutions are off, so a # is a #. Styling is stored as attributes, never as markup.

Real dot matrix

237 hand-built glyphs on a dim dot field. Accents, ligatures and every letter you need.

Instant writing

Live from the first moment. A wordmark greets an empty library and vanishes at the first keystroke.

Styling that stays quiet

Bold, italic, underline, strikethrough, lists and per-run colour. Stored as attributes, never markup.

Notes are files

Search everywhere

Up close

Every character is a grid of light.

Not a font on a grid — the dots themselves. The face is 5 × 8 cells, hand-built: 104 plain shapes, 16 letters no composition can make, 117 accented letters composed from the plain face.
